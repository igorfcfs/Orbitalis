# Scene assets

Real imagery and PBR textures for the habitat window, the sky, the studio lighting and the fabrics.
Everything else in the scene (habitat, hull, suit, characters) is drawn in code for this prototype.

| File | What it is | Source | License |
|---|---|---|---|
| `space/mars_4k.jpg` | Global map of Mars (8k original, resized to 4k) | Solar System Scope, based on NASA data | CC BY 4.0 |
| `space/milkyway_4k.jpg` | Milky Way sky (8k original, resized to 4k) | Solar System Scope, based on NASA and ESA data | CC BY 4.0 |
| `env/studio_2k.hdr` | Studio HDRI, used only as image-based lighting | Poly Haven, "Monochrome Studio 03" | CC0 |
| `tex/knit_nor.jpg`, `tex/knit_rough.jpg` | Knit fabric normal and roughness (not used since the coverall switched to woven cloth) | Poly Haven, "Jogging Melange" | CC0 |
| `tex/weave_nor.jpg`, `tex/weave_rough.jpg` | Woven fabric normal and roughness (coverall) | Poly Haven, "Rough Linen" | CC0 |
| `tex/paint_diff.jpg`, `tex/paint_nor.jpg`, `tex/paint_rough.jpg` | Painted metal (hatch) | Poly Haven, "Blue Metal Plate" | CC0 |

- Solar System Scope textures: https://www.solarsystemscope.com/textures/ (credit required, CC BY 4.0).
- Poly Haven: https://polyhaven.com/ (public domain, no credit required; listed here anyway).

The anatomy models in `public/models` are credited separately in `public/models/ATTRIBUTION.md`.
